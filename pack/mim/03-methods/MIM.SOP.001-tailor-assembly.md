# MIM.SOP.001 — Сборка занятия (Tailor Assembly)

## Назначение

Собрать **одно персональное занятие** для конкретного пользователя из готовых ячеек контента, адаптировав под профиль, состояние и ИТ-уровень. Каждое занятие — шаг к автономии (IWE, инструменты, самостоятельность).

> **Различение (DP.D.042):** Этот файл = SOP (КАК). Определение роли (ЧТО) → DP.ROLE.001 §3.2 R27. Реализация (ЧЕМ) → DS-IT-systems/aist_bot.

## Действие (7 шагов)

### Шаг 1. Прочитать профиль и состояние

**Вход:** `tailor_context` — срез ЦД через MCP endpoint `get_tailor_context(user_id)` → **[PD.SPEC.001](../../../PACK-personal/pack/personal-development/02-domain-entities/formalizations/PD.SPEC.001-tailor-context-contract.md)**
**Выход:** `context` — структура с полями: ступень, ИТ-уровень, состояние, энергия, стиль, домен, история

**Полный формат входа, fallback-правила и источники данных → PD.SPEC.001.**

**Правила:**
- Если L3 не вычислен (нет calculation engine) → fallback на L1 самооценку (правила fallback → PD.SPEC.001 §3)
- Если история пуста (новый пользователь) → ступень = 0 (Случайный), все глубины = 0 (MVP набор → PD.SPEC.001 §4)

### Шаг 2. Определить фазу программы

**Вход:** `context.ступень`
**Выход:** `phase` (1–4)

| Ступень | Фаза | Фокус |
|---------|------|-------|
| 0 Случайный | Ф1 Основания | Мотивация, мировоззрение, первые практики |
| 1 Практикующий | Ф1→Ф2 (переход) | Закрепление оснований + первые различения |
| 2 Систематический | Ф2→Ф3 | Различения + создание |
| 3 Дисциплинированный | Ф3→Ф4 | Создание + автономия |
| 4 Проактивный | Ф4 | Автономия, IWE, Pack, наставничество |

### Шаг 3. Выбрать область и тип воздействия

> **Обновлено (v3):** 6 направлений → 5 областей (PD.FORM.081). Добавлен выбор типа: мировоззрение или мастерство (PD.FORM.001 §5.1).

**Вход:** `phase`, матрица весов (§ Матрица), `context.история` (вчерашняя область)
**Выход:** `area` — одна из 5 областей + `impact_type` — мировоззрение или мастерство

**Пять областей (PD.FORM.081):**
1. Знания (понятия, различения, теории)
2. Инструменты (экзотело + экзокортекс, IWE)
3. Ограничения (состояния, триггеры, узкие места)
4. Окружение (среда, культура, калибр)
5. Организм (ресурсная база)

**Алгоритм:**
1. Взять веса областей для текущей фазы (§ Матрица)
2. **Корректировка по состоянию:**
   - Хаос → вес области 5 (Организм) × 2.0, вес области 1 (Знания) × 0.5
   - Тупик → вес области 3 (Ограничения) × 1.5, вес области 1 (Знания) × 1.5
   - Поворот → без корректировки
   - Развитие → вес области 2 (Инструменты) × 1.5
3. **Корректировка по энергии:** энергия ≤ 2 из 5 → вес области 5 (Организм) × 1.5
4. **Корректировка по доминирующей роли** (из Strategy.md или ЦД):
   Две области доминирующей роли получают множитель ×1.5.

   | Доминирующая роль | Основная (×1.5) | Вторая (×1.5) |
   |-------------------|----------------|---------------|
   | Ученик | 1 (Знания) | 3 (Ограничения) |
   | Интеллектуал | 1 (Знания) | 2 (Инструменты) |
   | Профессионал | 2 (Инструменты) | 1 (Знания) |
   | Исследователь | 1 (Знания) | 3 (Ограничения) |
   | Просветитель | 4 (Окружение) | 1 (Знания) |

   **Override:** срочная профессиональная потребность → вес области 1 (Знания) × 2.0.
5. **Ротация:** обнулить вес вчерашней области (R1 — не повторять 2 дня подряд)
6. Нормализовать веса → `доля_i = вес_i / сумма_весов`
7. Выбрать область: max(доля × gap)
8. **Выбор типа воздействия:**
   - Базовое соотношение по ступени (worldview / mastery):
     - Ступени 0-1: 80/20 (сначала «увидеть иначе»)
     - Ступени 2-3: 50/50 (баланс)
     - Ступень 4: 20/80 (акцент на «делать иначе»)
   - Если есть GAP-отчёт от Диагноста → корректировать: GAP мировоззрение > GAP мастерство → сдвиг к worldview, и наоборот
   - **Fallback (нет MCP tool / GAP-отчёта):** использовать базовое соотношение по ступени + weighted random

### Шаг 4. Выбрать элемент и глубину

**Вход:** `area`, `impact_type`, `context.глубины`, программа ЛР v3, CAT.001, CAT.002
**Выход:** `element_id` + `element_type` (meme | practice) + `depth` / `degree`

#### 4a. Выбор типа элемента

| impact_type | Каталог | Единица |
|---|---|---|
| `worldview` | CAT.001 (мемы) | мем с 3 глубинами (Осознание → Различение → Компиляция) |
| `mastery` | CAT.002 (практики) | практика с 4 степенями (Объяснение → Умение → Навык → Мастерство) |

#### 4b. Выбор элемента из каталога

**Для мемов (CAT.001):**
1. Отфильтровать мемы по `area` и текущей `phase`
2. Исключить мемы с `status: compiled` (пройдены все 3 глубины)
3. **Bottleneck-first:** выбрать мем с наибольшим gap (целевая глубина − текущая глубина)
4. При равном gap → round-robin по порядку в каталоге
5. `depth` = текущая глубина мема + 1

**Для практик (CAT.002):**
1. Отфильтровать практики по `area` и текущей `phase`
2. Исключить практики с `degree: mastery` (достигнута максимальная степень)
3. **Bottleneck-first:** выбрать практику с наибольшим gap по степени
4. При равном gap → приоритет практикам с ошибками в истории (2_3 ЦД)
5. `degree` = текущая степень практики + 1

#### 4c. Mastery-gate

**Не повышать** `depth` / `degree`, если can-do текущего уровня не подтверждено оценщиком.
- Мем: нет `can_do_passed` для текущей глубины → повторить текущую глубину
- Практика: нет `can_do_passed` для текущей степени → повторить текущую степень
- **Fallback:** нет истории оценок (новый пользователь) → начать с depth/degree = 1

#### 4d. Fallback (нет элементов в каталоге)

Если по выбранной `area` + `impact_type` нет элементов в каталоге:
1. Переключить `impact_type` на противоположный (worldview ↔ mastery)
2. Если снова нет → выбрать другую область (следующую по весу из шага 3)
3. Если каталог полностью пуст для фазы → генерация из руководства через knowledge-mcp (legacy fallback)

### Шаг 5. Собрать контент

**Вход:** `topic`, `bloom_depth`, ячейки DS-principles-curriculum, `dominant_role`
**Выход:** `raw_content` — урок + вопросы + задание

**Алгоритм:**
1. Найти ячейку: `cells/{topic}@{bloom_depth}`
2. Если ячейка есть → извлечь: can-do, методы, задания, формы подачи, bridge
3. **Fallback (нет ячейки):** генерация из руководств через knowledge-mcp + LLM (Haiku)
4. **Фильтр по типу воздействия (PD.FORM.001 §5.1):** Если `impact_type = worldview` → подбирать контент на компиляцию (мемы, различения, противоречие). Если `impact_type = mastery` → подбирать контент на постановку метода (задания, can-do, практика).

   **Фильтр по доминирующей роли (PD.D.138):** Для области «Знания» подбирать контент под тип знаний доминирующей роли:

   | Доминирующая роль | Тип знаний | Фокус контента |
   |-------------------|-----------|----------------|
   | Ученик | Ученические | Ритм, дисциплина, работа с текстом, ведение заметок |
   | Интеллектуал | Мыслительные | Системное мышление, понятия, моделирование, различения |
   | Профессионал | Профессиональные | Доменное мастерство, качество РП, наставничество |
   | Исследователь | Исследовательские | Гипотезы, эксперимент, анализ, расширение фронтира |
   | Просветитель | Просветительские | Публичное влияние, ясность изложения, масштабирование |

5. Встроить retrieval practice (FORM.007 R4): recall по 1–2 предыдущим темам
6. Встроить bridge (FORM.007 R2): «Помнишь, как мы [предыдущая тема]? Теперь...»

### Шаг 6. Адаптировать

**Вход:** `raw_content`, `context` (стиль, домен, ИТ-уровень, ошибки)
**Выход:** `adapted_content` — финальное занятие

**Адаптации:**

| Параметр | Как адаптировать |
|----------|-----------------|
| **Домен примеров** | Профессиональный домен пользователя (из ЦД). Разработчик → примеры с кодом. Менеджер → примеры с проектами |
| **Стиль подачи** | Краткий / подробный / с аналогиями (из ЦД L1) |
| **Ошибки** | Если в истории есть ошибки по теме → усиленный retrieval, дополнительный вопрос |
| **ИТ-уровень** | См. § Scaffolding ИТ-навыков |

## Матрица весов: фаза × область

> **Обновлено (v3):** 6 направлений → 5 областей (PD.FORM.081).
> **Base = область 1 (Знания)**, вес = 1.0.
> Остальные — относительно base. Доля = `вес_i / сумма_весов`.
> Веса корректируются по состоянию (шаг 3) и энергии.

### Ф1 Основания (Случайный → Практикующий)

| # | Область | Вес | Доля | Обоснование |
|---|---------|:---:|:----:|-------------|
| 1 | **Знания** | **1.5** | 33% | Фундамент: допущения, мировоззрение, мотивация, первые различения |
| 2 | Инструменты | 0.5 | 11% | Минимум: что такое экзокортекс и зачем |
| 3 | Ограничения | 0.8 | 18% | Осознание текущего состояния |
| 4 | Окружение | 0.7 | 16% | Кто рядом, что поддерживает |
| 5 | **Организм** | **1.0** | 22% | Ритм, сон, энергия — фундамент для всего |

### Ф2 Различения (Практикующий → Систематический)

| # | Область | Вес | Доля |
|---|---------|:---:|:----:|
| 1 | **Знания** | **1.0** | 22% |
| 2 | **Инструменты** | **1.0** | 22% |
| 3 | Ограничения | 0.8 | 17% |
| 4 | Окружение | 0.8 | 17% |
| 5 | Организм | 1.0 | 22% |

### Ф3 Создание (Систематический → Дисциплинированный)

| # | Область | Вес | Доля |
|---|---------|:---:|:----:|
| 1 | Знания | 0.8 | 16% |
| 2 | **Инструменты** | **1.5** | 30% |
| 3 | Ограничения | 0.8 | 16% |
| 4 | Окружение | 0.5 | 10% |
| 5 | **Организм** | **1.4** | 28% |

### Ф4 Автономия (Дисциплинированный → Проактивный)

| # | Область | Вес | Доля |
|---|---------|:---:|:----:|
| 1 | Знания | 0.8 | 15% |
| 2 | **Инструменты** | **1.8** | 34% |
| 3 | Ограничения | 0.5 | 10% |
| 4 | **Окружение** | **0.8** | 15% |
| 5 | **Организм** | **1.4** | 26% |

> **Тенденция:** Ф1 → Знания + Организм. Ф2 → Ровно. Ф3-Ф4 → Инструменты + Организм.
>
> **Различие с ведущими областями FORM.080/081:** FORM.080 §9 определяет ведущие области для **перехода ступени** (gate-критерии). Матрица весов SOP.001 определяет приоритет **ежедневных занятий** (контент). Они могут расходиться: gate требует Окружение на 4→5, но ежедневные занятия усиливают Инструменты + Организм как фундамент. Ведущие области gate = стратегическая цель. Веса матрицы = тактический баланс.

## Scaffolding ИТ-навыков

> **Принцип:** Портной не просто адаптирует формат — он **ведёт к IWE**. Каждое занятие приближает к самостоятельности с инструментами. Это scaffolding (MIM.M.006), встроенный в задания.

### Траектория по ИТ-уровням

| ИТ-уровень | Что в занятии | Куда ведёт | Примеры заданий |
|:---:|------------|-----------|-----------------|
| 0 | Всё через бот. Подводки: «Это можно сохранить в файл — скоро покажем как». Ссылки на обзорные видео «что такое VS Code / Git / CLI» | → ИТ=1 | «Посмотри 5-минутное видео о VS Code. Что понравилось?» |
| 1 | Бот + простые инструкции. Рекомендации изучить инструменты по видео/курсам. Первые шаги: «Открой VS Code, создай файл» | → ИТ=2 | «Установи VS Code по инструкции. Создай файл "мои-допущения.md"» |
| 2 | Задания с IWE: заметки в экзокортексе, тайм-трекер, черновики | → ИТ=3 | «Создай заметку в inbox, запиши 3 различения из занятия» |
| 3 | Задания через IWE: Claude Code, анализ Pack, автоматизация | Автономия | «Используй Claude Code для анализа своих допущений vs ZP.1» |

### Правила scaffolding

- **R-IT.1:** Каждое занятие содержит `it_scaffolding` — подводку к следующему уровню ИТ
- **R-IT.2:** Не перескакивать: ИТ=0 не получает заданий с VS Code. Только подводки и видео
- **R-IT.3:** Ссылки на внешние ресурсы (видео, курсы) = часть контента. Портной подбирает релевантные
- **R-IT.4:** Переход ИТ-уровня = событие в ЦД. Фиксируется при успешном выполнении задания уровня N+1
- **R-IT.5:** «Пропитаться» важнее «установить». Сначала — зачем (видео, примеры, истории), потом — как (инструкция)

## Правила

| # | Правило | Источник |
|---|---------|----------|
| R1 | **Ротация:** Не повторять область 2 дня подряд (кроме bottleneck-sprint) | Этот SOP |
| R2 | **Retrieval:** Каждое занятие начинается с recall предыдущего | FORM.007 R4 |
| R3 | **Bridge:** Связь с предыдущим занятием по той же области | FORM.007 R2 |
| R4 | **Mastery-gate:** Не повышать глубину без прохождения can-do | FORM.007 R3 |
| R5 | **Fallback:** Нет ячейки → генерация из руководства через knowledge-mcp | Этот SOP |

## Ограничения

1. **Портной ≠ Автор.** Контент уже существует (ячейки, руководства). Портной компонует, не создаёт
2. **Портной ≠ Диагност.** Портной читает диагноз из ЦД, не проводит диагностику
3. **Портной ≠ Методист.** Методика — в PACK-MIM. Портной применяет, не проектирует
4. **Fallback ≠ норма.** Генерация из руководств — временная мера. Цель: 100% ячеек готовы
5. **Матрица — гипотеза.** Веса подлежат калибровке по данным (engagement, completion rate, прогресс)
