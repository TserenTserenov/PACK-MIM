## Definition

Пологий вход — pedagogical design pattern: при введении нового эмоционального состояния (или любого состояния без прямого аналога в текущей карте участника) — первый шаг НЕ боевой контент, а metamaterial: описание нового состояния **через язык уже знакомых участнику понятий**.

Цель: дать участнику «точку опоры» в уже существующей карте понятий, прежде чем он входит в новое состояние.

## Purpose

Предотвратить ситуацию, когда новое состояние остаётся абстракцией: участник прочитал определение, но не нашёл, к чему его прикрепить в своём опыте. Metamaterial — мост, а не дополнительный учебный модуль.

## Distinction from Direct Content Introduction

| Direct entry | Gentle entry (этот метод) |
|---|---|
| Новое состояние описывается своими словами («Хаос — это…») | Новое состояние описывается через уже знакомые понятия («В карте 14 узлов Хаос — это…») |
| Участник строит карту с нуля | Участник расширяет существующую карту |
| Высокое когнитивное сопротивление | Низкое сопротивление (есть якорь) |

## Inputs

| Input | Description |
|-------|-------------|
| Карта понятий участника | Что уже знает/использует (N понятий) |
| Новое состояние | Что вводится (эмоциональное/концептуальное) |
| Боевой контент | Основной учебный материал по новому состоянию |

## Outputs

| Output | Description |
|--------|-------------|
| Metamaterial (мост) | Описание нового состояния через ≥1 уже знакомых понятий |
| Готовность к боевому контенту | Участник имеет точку опоры для обработки основного материала |

## Forces

_(Optional, WP-448 Ф10) Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Опора на знакомую карту ↔ подлинность нового состояния | Metamaterial описывает новое состояние через уже знакомые понятия, снижая когнитивное сопротивление, но чрезмерное сведение нового к старому рискует притупить именно то, что делает новое состояние новым — часть подлинного опыта может потеряться в переводе на знакомый язык |
| Мост как отдельный шаг ↔ дополнительная учебная нагрузка | Purpose явно отделяет metamaterial от «дополнительного учебного модуля» («мост, а не модуль»), но фактически это ещё один шаг перед боевым контентом — экономия когнитивного сопротивления достигается ценой дополнительного времени на сам мост |
| Универсальность метода ↔ индивидуальность карты каждого участника | Метод строится на «карте понятий участника», но в групповой программе у разных участников разные карты (Волна-1 могла восприниматься по-разному) — один и тот же metamaterial-мост не обязательно одинаково работает для всех |

## Bias-Annotation _(tentative — sota: forming, метод недавний, единственный источник WP-330)_

_(Optional, WP-448 Ф10) Какое систематическое искажение грозит практикующему._

| Bias | Direction of distortion |
|------|--------------------------|
| Metamaterial подменяется прямым определением с косметической ссылкой на старое понятие | Тест метода требует хотя бы один реально знакомый концепт как якорь, но при спешке автор может просто упомянуть знакомый термин вскользь («это похоже на…») без выстраивания настоящего моста — формально Distinction соблюдён (есть отсылка), а по существу это уже Direct entry под видом Gentle entry |
| Оценка «участник имеет точку опоры» делается по намерению автора, а не по факту участника | Outputs требует «готовность к боевому контенту», но эта готовность проверяется субъективно самим автором программы, который спроектировал мост — реальная проверка (есть ли у конкретного участника этот знакомый концепт в его личной карте) легко подменяется предположением о типичном участнике |

## Test

«У участника есть хотя бы один уже знакомый концепт, через который вводится новое состояние?»
- Нет → добавить пологий вход (metamaterial) перед основным контентом.

## When to Apply

- Программы с несколькими «волнами» (участник Волны-2 имеет карту из Волны-1)
- Введение эмоциональных состояний (Хаос, Тупик, Кризис)
- Любой переход, где новое состояние не имеет прямого аналога в текущей карте участника
