# MIM.PRG.002 — Программа рабочего развития

> Система «железный человек» осваивает текущий state of the art для работы и выдаёт «шедевры» через резидентуры.

## Summary

Программа рабочего развития направлена на то, чтобы система «железный человек» нашла и освоила текущий state of the art для работы и начала выдавать внешне предъявляемые рабочие результаты высокого качества. Основной формат — резидентура (MIM.FMT.003). Участник уже подтвердил готовность по результатам личного развития и теперь применяет собранную систему «человек + ИИ» для создания «шедевра».

## Направленность

**Что развиваем:** способность системы «человек + ИИ» находить, осваивать и применять текущий state of the art в рабочей деятельности для получения результатов высокого качества.

## Основной формат

**Резидентура** (MIM.FMT.003) — работа над своим шедевром с наставничеством (MIM.M.002).

## Результат

- Отчуждаемый: **шедевр** (MIM.WP.002) — внешне предъявляемый рабочий результат
- Критерии шедевра заданы заранее
- Проект свой (не выдан начальником)

## Вход из личного развития

Рабочее развитие — следующий этап после программы личного развития (MIM.PRG.001), а не её параллельная замена. Зачисление требует:

- подтверждённой готовности человека по канонической модели завершения личного развития;
- отдельной проверки операционной готовности к конкретной редакции программы, включая способность выполнить её рабочий процесс в используемой ИИ-среде.

Вторая проверка не меняет ступень личного развития: она относится к допуску в программу.

## Структура программы

Число резидентур, продолжительность, нагрузка, порядок тем и конфигурация встреч задаются конкретной редакцией программы. Они не входят в определение программы рабочего развития. Допустима одна непрерывная резидентура, объединяющая несколько областей знания, если сохраняются инварианты MIM.FMT.003: собственный реальный проект, заранее согласованный результат, критерии качества, регулярные разборы и наставничество.

## Обязательные элементы

- Договорённость о результате с самого начала
- Еженедельные разборы (MIM.FMT.004)
- Наставничество через review (MIM.M.002)
- Информационные ресурсы и инструменты трекинга
- Замер квалификации (MIM.WP.003) на каждом разборе

## Чем отличается от личного развития (MIM.PRG.001)

| Рабочее развитие | Личное развитие |
|------------------|-----------------|
| Резидентура — работа | Практикум — тренировка |
| Рабочий результат (шедевр) | Изменение человека; проект — материал практики |
| Готов применять освоенный способ работы | Осваивает способ работы |
| «Что я сделал» | «Как я изменился» |

## Типичная ошибка

Попытка выдать рабочий результат без подтверждённой готовности → шедевр не получается → разочарование. Нужно сначала завершить личное развитие (MIM.PRG.001) либо предъявить эквивалентные свидетельства готовности, предусмотренные конкретной редакцией программы.
