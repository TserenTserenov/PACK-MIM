# MIM.PRG.003 — Программа исследовательского развития

> Система «железный человек» выходит на фронтир и создаёт новый state of the art.

## Summary

Программа исследовательского развития направлена на то, чтобы система «железный человек» вышла на фронтир и создала новый state of the art — знание, которым потом будут пользоваться другие. Основной формат — семинар (MIM.FMT.001). Результат — коллективное понимание нового и зафиксированный вклад в знание.

## Направленность

**Что развиваем:** способность системы «человек + ИИ» создавать новое знание на фронтире, расширяя границы доступного и формируя state of the art для сообщества.

## Основной формат

**Семинар** (MIM.FMT.001) — доклад и обсуждение нового знания.

## Результат

- Отчуждаемый: **слайдомент** (MIM.WP.001) — фиксация создаваемого нового знания
- Неотчуждаемый: коллективное понимание нового материала
- Через время материал становится руководствами и основой для практикумов

## Обязательные элементы

- Докладчик (MIM.R.002) с экспертизой в предмете
- Вопросы на понимание + проблематизацию
- Длительность: от пары часов до целого дня (6 часов)
- Слайдоменты как основной материал

## Место в цепочке развития

```
Личное развитие → Рабочее развитие → Исследовательское развитие
(создание «железного человека»)   (освоение SoTA для работы)   (создание SoTA на фронтире)
Практикум → Резидентура → Семинар
```

Практикум создаёт «железного человека». Резидентура направляет его на освоение текущего state of the art в работе. Семинар выводит на фронтир, где создаётся новое знание. Послушать ≠ научиться (MIM.D.001); для создания SoTA нужна сначала система «человек + ИИ», затем освоение существующего SoTA.

## Ключевая особенность МИМ

Слайдомент можно сразу использовать с AI-агентом для обсуждения и пробной работы по новым методам — это мостик между «послушал» и «начал тренироваться».

## Типичная ошибка

«Послушал = научился» (MIM.FM.001): после семинара участник считает, что уже освоил материал → пропускает практикум → ошибки при попытке применить.
