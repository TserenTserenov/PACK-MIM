# MIM.FORM.009 — Трёхслойная модель контента программы развития

> Абстрактный принцип организации содержания в программах типа MIM.PRG.001. Не конкретный контент, не платформенная реализация.

## 1. Назначение

Любая программа развития, направленная на изменение самого человека (не рабочего результата), сталкивается с тремя противоречиями:

1. **Единое vs персональное.** Универсальные принципы работают для всех, но каждый ученик находится в уникальном состоянии.
2. **Теория vs практика.** Знание без применения не меняет поведение; механическая практика без осмысления закрепляет ошибки.
3. **Структура vs адаптация.** Жёсткий план гарантирует полноту, но игнорирует текущее состояние ученика.

Трёхслойная модель — это способ разрешить все три противоречия одновременно, не сводя их к компромиссу.

## 2. Три слоя

| Слой | Что это | Функция | Уровень абстракции |
|------|---------|---------|-------------------|
| **L3 — Персональное руководство** | Ежедневный контекстный срез: что делать сегодня, учитывая текущее состояние | Адаптация универсального к уникальному | Конкретный: «сегодня», «этот ученик» |
| **L2 — Универсальные руководства** | Систематизированное содержание программы: методы, принципы, различения | Передача структуры и полноты | Абстрактный: «всегда», «типовой ученик» |
| **L1 — Практикумы** | Структурированные периоды тренировки с наставником и когортой | Создание условий для deliberate practice | Промежуточный: «этот модуль», «эта когорта» |

**Почему именно три, а не два или четыре:**

- **Два слоя** (теория + практика) не решают проблему адаптации: ученик получает либо абстрактную теорию, либо конкретное задание без понимания, почему именно оно.
- **Четыре слоя** вносят избыточное разделение (например, «методы» vs «принципы»), которое не меняет функцию слоя, а только усложняет навигацию.
- **Три слоя** дают минимальную структуру, покрывающую все три противоречия: L2 хранит универсальное знание, L1 создаёт условия для практики, L3 адаптирует к текущему состоянию.

## 3. Как слои соотносятся

**Не замещение, а композиция.**

```
L3 (Персональное руководство)
  ← собирается из L2 + состояние ученика
L2 (Универсальные руководства)
  ← пополняется из результатов L1 (что работает, что нет)
L1 (Практикумы)
  ← проектируются из L2: какие методы тренировать
```

- L3 не существует без L2: персональное руководство выбирает фрагменты из универсального.
- L1 не существует без L2: практикум тренирует методы, описанные в руководствах.
- L2 развивается благодаря L1: обратная связь из практикумов обогащает универсальное содержание.

## 4. Привязка слоёв к состояниям ученика

Каждый слой работает как инструмент на определённых переходах состояния (PD.FORM.089). Это не жёсткая привязка «ступень = слой», а доминирующий инструмент для типичного перехода:

| Переход состояния | Доминирующий слой | Почему |
|-------------------|-------------------|--------|
| Вход → ст. 1 (Случайный) | L1 (Практикум) | Человек ещё не умеет самостоятельно работать с содержанием; нужна внешняя структура и обратная связь |
| Ст. 1 → 2 (Случайный → Практикующий) | L1 + L2 | Практикум формирует первые навыки; руководство даёт понимание, куда движемся |
| Ст. 2 → 3 (Практикующий → Систематический) | L2 + L3 | Навыки выстроены, нужна система; персональное руководство помогает удержать ритм |
| Ст. 3 → 4 (Систематический → Дисциплинированный) | L3 (доминирует) | Методы освоены, фокус — на персональной адаптации и расширении |
| Ст. 4 → 5 (Дисциплинированный → Проактивный) | L3 + обратная связь в L2 | Автономный ученик сам генерирует инсайты, которые обогащают универсальное содержание |

**Ключевое различение:** слой — это инструмент процесса, а не характеристика ученика. Один и тот же ученик на ступени 3 может использовать все три слоя одновременно: практикум (L1) для нового метода, руководство (L2) для понимания контекста, персональное руководство (L3) для планирования дня.

## 5. Принцип прогрессии

По мере роста мастерства меняется не только содержание, но и **соотношение слоёв** в ежедневной практике:

| Ступень | Соотношение L1:L2:L3 | Что меняется |
|---------|----------------------|--------------|
| 1 | 70:20:10 | Большая часть времени — в практикуме; руководство — справочник; персонализация минимальна |
| 2 | 50:30:20 | Практикум укорачивается; руководство становится основой самостоятельной работы |
| 3 | 30:30:40 | Практикум — точечный (новые методы); руководство — фон; персональное руководство — основа |
| 4 | 10:20:70 | Практикум — редкий (только новые навыки); персональное руководование — главный инструмент |
| 5 | 0:10:90 | Автономия: практикум не нужен; обратная связь идёт в L2, а не из L2 |

**Механизм прогрессии:** MIM.FORM.008 (mastery-gate). Переход на следующую ступень открывает доступ к большей доле L3 и сокращает необходимость L1. Deliberate practice (MIM.M.001) при этом не исчезает — она переносится из внешне организованного практикума (L1) в самоорганизованную практику под управлением L3.

## 6. Применимость

Этот принцип применим к любой программе развития типа MIM.PRG.001:

- **Личное развитие** (MIM.PRG.001): L2 = методы саморазвития, L1 = практикумы S1–S4, L3 = персональное руководство Портного.
- **Рабочее развитие** (MIM.PRG.002): L2 = профессиональные методы, L1 = резидентуры, L3 = персональный план развития.
- **Исследовательское развитие** (MIM.PRG.003): L2 = принципы исследования, L1 = семинарские циклы, L3 = персональная исследовательская повестка.

Конкретное наполнение слоёв — downstream. Этот документ фиксирует только архитектурный принцип.
